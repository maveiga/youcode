🔧 Como personalizar as cores do Spline

Use filters CSS para ajustar as cores sem precisar recriar a cena no Spline. Experimente os valores abaixo no seu index.html:

.hero-spline spline-viewer { filter: hue-rotate(200deg) saturate(0.5) brightness(1.3); }

Dica: Para uma solução perfeita, crie sua cena diretamente no spline.design usando materiais brancos (#FFFFFF) e azuis (#1a56db, #3b73f0).
